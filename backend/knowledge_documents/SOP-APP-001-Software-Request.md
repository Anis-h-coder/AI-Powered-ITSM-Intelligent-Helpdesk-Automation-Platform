# Software Installation and Provisioning Request
Category: Software & Licensing
Approval: Assessment sample procedure; replace with the organization's approved software catalog and approval policy before production use.

## Steps
1. Search the organization's approved software catalog for the requested application and platform.
2. Submit a service request containing the software name, business purpose, device identifier and requester department.
3. Check whether a license, manager approval or security review is required. Do not grant admin privileges or install software outside the approved catalog.
4. Record the request ID and show its actual status from the service-request system.
5. Provisioning is complete only after an authorized deployment system confirms installation. A submitted request or simulated response must not be displayed as completed installation.
6. Escalate unavailable catalog items, paid licenses, elevated privileges or software with unverified publishers to IT Asset Management/Security.
