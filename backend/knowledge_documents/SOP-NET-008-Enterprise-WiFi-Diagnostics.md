# Enterprise Wi-Fi Connectivity Checks
Category: Network & Connectivity
Approval: Assessment sample procedure; replace with the organization's approved wireless SOP before production use.

## Steps
1. Confirm Wi-Fi is enabled and airplane mode is off.
2. Confirm the employee is selecting the official corporate SSID, not a similarly named network.
3. Check whether other approved company services work and capture the exact connection error.
4. If permitted by endpoint policy, disconnect and reconnect to the corporate network using the normal sign-in flow. Do not bypass certificate validation or install an unknown certificate.
5. Record the device type, operating system, location/building and time of failure for network support.
6. Escalate certificate warnings, repeated authentication failures or reports affecting multiple employees.
