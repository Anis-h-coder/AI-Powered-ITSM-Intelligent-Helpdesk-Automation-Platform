# Outlook Mail Synchronization Troubleshooting
Category: Email & O365
Approval: Assessment sample procedure; replace with the organization's approved M365 SOP before production use.

## Steps
1. Check whether Outlook on the web is available. If both web and desktop access fail for multiple employees, report a possible service incident to the collaboration support team.
2. Confirm the device has network access and that Outlook is not in Work Offline mode.
3. Restart Outlook and check whether the affected mailbox folder begins synchronizing.
4. Record the exact error, Outlook version, operating system and approximate start time. Do not collect mailbox contents or authentication tokens.
5. Do not delete an OST/PST file or recreate a profile without following the organization's approved procedure and confirming that data is synchronized or backed up.
6. Escalate if synchronization remains stuck, there is a data-loss concern, or multiple users are affected.
